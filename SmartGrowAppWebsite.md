**Email Notification Requirement:**

Whenever a visitor submits the contact form:

- Validate all mandatory fields.
- Submit the enquiry securely to the backend.
- Trigger an automatic email notification to the configured SmartGrowApp business email address.
- Include all submitted customer details in the email.
- Include submission date and time.
- Include the requested service.
- Include the complete project description.
- Use a professional HTML email template.
- Display proper success and error messages.
- Prevent duplicate submissions.
- Implement spam protection using appropriate validation and CAPTCHA or honeypot techniques.

Use a server-side email service such as Resend.

Keep the email service API key securely in Vercel environment variables. Never expose API keys, SMTP passwords, or secrets in frontend JavaScript.

Do not hardcode an unconfirmed business email address. Make the recipient configurable using an environment variable.

Suggested configuration:
- RESEND_API_KEY
- CONTACT_TO_EMAIL
- CONTACT_FROM_EMAIL

Implement the contact submission using a secure server-side API route or serverless function compatible with Vercel.

If email delivery fails, preserve the customer's enquiry where possible and show an appropriate error message rather than falsely reporting success.
